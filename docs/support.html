Support

The app has a full user guide: tap the ? button at the top of the screen. Common questions are answered below.

Common questions

The speaker display is blank, or the app says "No display"

Check the HDMI cable or AirPlay screen mirroring. The app finds the screen automatically when it connects.

Start is greyed out

There's no time on the clock. Set a time or tap a quick time first.

The Sync button stays yellow

It hasn't found another iPad yet. Check that every iPad uses the same show code, has Wi-Fi and Bluetooth turned on, and has the app open. If iOS asked about Local Network access, allow it in Settings › Privacy & Security › Local Network.

A message went up on its own

It was waiting in the message box when the timer reached 00:00, so it was sent automatically. Clear the message box if you don't want that.

The screen turned off during a talk

The iPad locked itself. Before an event, open Settings › Display & Brightness › Auto-Lock and choose Never, and keep SpeechCue Timer open while a talk is running.

Contact
